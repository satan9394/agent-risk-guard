## 交付内容

### 1. ACS version gate（§一~§六）

核心原则（§五十六）：**Protocol version mismatch must fail explicitly.**

| 概念 | 判据 | 结果 |
|---|---|---|
| schema-valid | `params.acs_version` 匹配 `^\d+\.\d+\.\d+$` | envelope 层校验通过 |
| supported | 精确 ∈ `SUPPORTED_ACS_SPEC_VERSIONS = ['0.1.0']` | gateway 放行 |
| schema-invalid（如 `0.1`） | 非完整 SemVer | `-32602 Invalid params` |
| unsupported（如 `0.2.0` / `1.0.0` / `9.9.9`） | schema-valid 但不在支持集 | `-32001 Unsupported ACS version` |

实现：

- `packages/acs/src/version.ts`：新增 `SUPPORTED_ACS_SPEC_VERSIONS`、`isSupportedAcsVersion()`、
  `getSupportedAcsVersions()`（§二/§六；精确 pin，禁止 0.1.x / 0.x / latest / semver range / negotiation）。
- `packages/acs/src/types.ts`：`ACS_JSONRPC_CODES.UNSUPPORTED_ACS_VERSION = -32001`（ACS application error
  区间 -32000 ~ -32099，§四）。
- `packages/acs/src/gateway.ts`：`evaluateAcsEnvelope()` 在 envelope 校验通过后、payload 校验前插入 version gate
  （§四）——unsupported 直接返回 `-32001` error envelope，**绝不进入 RiskEvent / Policy Engine**，也**绝不返回
  security policy DENY**（协议能力不匹配 ≠ 危险操作判断）。

### 2. Release workflow（§七~§十）

新增 `.github/workflows/release.yml`：

- 触发：`push: tags: v*`。
- Release Gate（`verify` job，Node 22/24 matrix）：`npm ci` → schema snapshot 校验 → build artifact →
  `sha256sum -c SHA256SUMS.txt`（hash PASS）→ 全量 platform-independent 测试（tests PASS）→ 任一失败则不上传。
- `release` job（`needs: verify`，仅跑一次）：build artifact → 生成根目录 `SHA256SUMS.txt`（覆盖 archive）→
  `gh release create`（`--prerelease --generate-notes`）上传 `dist/*.tar.gz` + `dist/SHA256SUMS.txt`。
