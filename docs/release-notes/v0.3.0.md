## 中文

### 这一版要解决什么问题

到 v0.2.2 为止，"RiskGuard 能拦住危险命令"这句话的证据，**全部来自我们自己的单元测试和文档**。
没有任何一条证据来自**真实的 Agent 会话** —— 也就是说，没有人证明过：在一个真的 AI 编码会话里，
模型发出危险命令时，它**在工具执行前**被拒绝，并且文件**确实还在**。

这是这个项目最不该留的窟窿：一个安全产品如果只有自测，那它宣称的保护就是**假安全感**。
同时，一次 5 个独立判别器的对抗审查（GAN 式 maker-checker）在共享规则和适配器里挖出了
**17 条真实绕过**（P0×10 / P1×6 / P2×1）—— 大小写绕过、fail-open、落盘后执行、插词变体、
base64 管道、`git restore/checkout`、`xargs`/`execdir` 落空、工具名匹配盲区等。

### 改变了什么

- **5-Agent 真实会话一致性验证**：OpenCode / Claude Code / DSH / AGY 拿到 **D3** 硬拦截证据（真实会话中
  `git reset --hard` 被拒、未提交改动存活）；Codex 应用形态拿到真实会话拦截确认，且**如实标注拦截来源是
  Codex 自身的 `approval_policy=never` + `sandbox=unelevated` 策略层，不是我们的 hook**（hook 在应用会话的触发待补测）。
- **GAN 对抗审查 17/17 全部修复**：含大小写绕过、fail-open、落盘执行、插词/包装/换名变体、`-xec` 解包、
  `os.system`/`os.popen`、`EncodedCommand`/base64、`git restore`/`checkout`、拆拼/变量拼接/转义、`xargs`/`execdir`、
  工具名匹配盲区、`ri`/`echo del` 误伤；并把修复同步进单一规则源 `defaultDenyRules()`（消除双源漂移）。
- **installer UX**：`detect` 遍历全量 Agent registry；`install` 无 `--agent` 时**交互式编号选择**，
  非 TTY / 管道 / 超时 / EOF 一律回退默认全装（绝不挂起）。
- **新增 `packages/adapters/agy`**（Antigravity CLI）：首个"适配器 + 共享规则 + 真实 D3 标注"的**完整样板**，
  后续接入新 Agent 可以照抄这条链路。
- **ps1 / 插件事务资产入仓库**（`assets/`）：monorepo 成为脚本规则的单一事实源，CC / Codex / AGY 生产接线从它同步。

### 验证

真实会话证据汇总见 `docs/real-agent-conformance-final-report.md`；各 Agent 等级在
`packages/installer/compatibility.json` 更新（agy 新增 D3；Codex 升 D3 并注明来源）。CI 全绿。

定位仍是 **Developer Preview**：macOS / Linux 与 Copilot CLI / Windsurf / Cursor 的真实 D3 待补，不宣称 1.0 Stable。

## English

### The problem this release solves

Up to v0.2.2, every piece of evidence behind "RiskGuard blocks dangerous commands" came from **our own unit
tests and documentation**. Not one piece came from a **real agent session** — nobody had demonstrated that,
in an actual AI coding session, a dangerous command is refused **before the tool runs** and the file is
**still there**.

That is the one hole a security project must never leave: a guardrail backed only by self-tests is
**false confidence**. At the same time, a 5-discriminator adversarial review (GAN-style maker-checker)
found **17 real bypasses** (P0×10 / P1×6 / P2×1) in the shared rules and adapters — case bypass, fail-open,
drop-to-disk-then-run, word-insertion variants, base64 piping, `git restore/checkout`, `xargs`/`execdir`
misses, tool-name blind spots, and more.

### What changed

- **5-agent real-session conformance**: OpenCode / Claude Code / DSH / AGY earned **D3** hard-block evidence
  (a real session's `git reset --hard` was refused and uncommitted changes survived). The Codex app form got a
  real-session block confirmation **honestly attributed to Codex's own `approval_policy=never` +
  `sandbox=unelevated` policy layer, not to our hook** (hook triggering inside app sessions still to be tested).
- **All 17 adversarial findings fixed**: case bypass, fail-open, drop-to-disk execution, word-insertion /
  wrapper / rename variants, `-xec` unwrapping, `os.system`/`os.popen`, `EncodedCommand`/base64,
  `git restore`/`checkout`, split/concatenated/escaped spellings, `xargs`/`execdir`, tool-name blind spots,
  and false positives like `ri` / `echo del`. Fixes were synced into the single rule source
  `defaultDenyRules()` (removing a dual-source drift).
- **Installer UX**: `detect` walks the full agent registry; `install` without `--agent` offers an
  **interactive numbered selection**, falling back to "install all" on non-TTY / pipe / timeout / EOF (never hangs).
- **New `packages/adapters/agy`** (Antigravity CLI): the first **complete sample** of
  adapter + shared rules + real D3 annotation — copy this chain when wiring a new agent.
- **ps1 / plugin transactional assets moved into the repo** (`assets/`): the monorepo is now the single rule
  source that CC / Codex / AGY production wiring syncs from.

### Verification

Real-session evidence is collected in `docs/real-agent-conformance-final-report.md`; per-agent levels were
updated in `packages/installer/compatibility.json` (agy added at D3; Codex raised to D3 with its source noted).
CI is green.

Still a **Developer Preview**: real D3 for macOS / Linux and for Copilot CLI / Windsurf / Cursor is pending,
so this does not claim 1.0 Stable.
