## 中文

### 这一版要解决什么问题

在这一切之前，AI 编码 Agent 可以**永久删除文件、抹掉未提交的改动**，而唯一的防线是
"**希望模型遵守写在 AGENTS.md / CLAUDE.md 里的文字规则**"。文字规则是**建议**，不是门禁：
模型可以忽略、可以被绕过、可以因为一次上下文漂移就照做。没有确定性策略引擎，也没有回收站兜底 ——
删除就是删除，不可恢复。

### 改变了什么

- **M1 Core**：RiskEvent v1 / Decision v1 / risk taxonomy / path-resolver / normalize / policy-engine / audit
  （纯函数内核，无副作用）。
- **M2 CLI Runtime + DSH 插件接线**：stdin JSON → Decision JSON（供 command hook 使用），
  delete → deny + trash、write → allow、git_clean → deny、strict、fail-closed；
  DSH `pre-execute` 动态策略 + 单调 `ctx.tools.guard()` + junction 逃逸防护。
- **M3 Hook Family**：claude / cursor / grok / windsurf command hooks（Windows ps1 + macOS/Linux sh 规则同步）。
- **M4 Plugin Family**：opencode `tool.before` TS 插件。
- **M5 Codex**：rules-compiler 把 defaultPolicy 编译为 AGENTS.md / CLAUDE.md（单一事实源）。
- **M6 Installer**：discovery / deploy / backup / rollback / uninstall / doctor。
- **M7 行为级加固**：`resolveReal()`（fs.realpath）+ junction 逃逸 **D3 实测**；DSH pre-execute 内嵌
  `checkJunctionEscape`。
- **trash 包**：Windows 回收站（**D3 实测 2/2**）、macOS Trash、freedesktop Trash —— 删除走向可恢复，
  而不是"拒绝一切"。
- **对抗防御**：全角字符 / NFKC 归一化、引号插词、`$()` / 反引号包裹、base64 管道、路径穿越、
  subprocess / execSync 动态执行、`reg delete` / `certutil` / `docker run|exec` / `git gc --prune` /
  `git reflog expire` 等向量。
- **GAN 式独立判别器对抗审查**：core / installer / opencode / adapter / hook 五轮 maker-checker 独立评审闭环。

### 验证

本机生产部署（DSH patch、codex/CC hook、opencode 插件）已同步；**D3 三 Agent 删除实测全部拒绝永久删除并走回收站**；
全量 22 组测试通过（含 70+ 条对抗语料）。同日完成 SkillHub 平台发布与 GitHub 开源。

## English

### The problem this release solves

Before any of this, an AI coding agent could **permanently delete files and wipe uncommitted work**, and the only
defence was "**hope the model follows the written rules in AGENTS.md / CLAUDE.md**". Written rules are
**advice**, not a gate: a model can ignore them, be talked around them, or drift and comply anyway. There was no
deterministic policy engine and no trash fallback — a deletion was a deletion, unrecoverable.

### What changed

- **M1 Core**: RiskEvent v1 / Decision v1 / risk taxonomy / path-resolver / normalize / policy-engine / audit — a
  pure-function core with no side effects.
- **M2 CLI runtime + DSH plugin wiring**: stdin JSON → Decision JSON for command hooks (delete → deny + trash,
  write → allow, git_clean → deny, strict, fail-closed); a DSH `pre-execute` dynamic policy plus a monotonic
  `ctx.tools.guard()` invariant and junction-escape protection.
- **M3 Hook family**: claude / cursor / grok / windsurf command hooks (Windows ps1 with matching macOS/Linux sh
  rules).
- **M4 Plugin family**: an opencode `tool.before` TS plugin.
- **M5 Codex**: a rules-compiler that compiles the default policy into AGENTS.md / CLAUDE.md from a single source.
- **M6 Installer**: discovery / deploy / backup / rollback / uninstall / doctor.
- **M7 behaviour-level hardening**: `resolveReal()` (fs.realpath) with **D3-tested** junction-escape protection,
  and `checkJunctionEscape` embedded in the DSH pre-execute path.
- **The trash package**: Windows Recycle Bin (**D3 verified 2/2**), macOS Trash, freedesktop Trash — so deletion
  becomes recoverable instead of "block everything".
- **Adversarial defences**: fullwidth characters / NFKC normalisation, quote insertion, `$()` / backtick wrapping,
  base64 piping, path traversal, subprocess / execSync dynamic execution, and vectors such as `reg delete` /
  `certutil` / `docker run|exec` / `git gc --prune` / `git reflog expire`.
- **GAN-style independent adversarial review**: five maker-checker rounds across core / installer / opencode /
  adapter / hook.

### Verification

Production wiring on the author's machine (DSH patch, codex/CC hooks, opencode plugin) was synced; **all three
agents in the D3 deletion test refused permanent deletion and routed to the Recycle Bin**; 22 test groups passed
(including 70+ adversarial payloads). SkillHub publication and the GitHub open-sourcing happened the same day.
