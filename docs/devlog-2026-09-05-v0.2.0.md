## 本轮目标

四个核心工程能力（v0.2.0 目标 §一）：

1. Compatibility Schema v2（真实执行边界）
2. ACS Event Gateway（ToolCallRequest → RiskEvent）
3. ACS Result / Verdict Gateway（Decision → ACS Result）
4. Agent Security Conformance Framework（C1–C10）

核心原则：**ACS is an interoperability layer, not the RiskGuard core**；
RiskEvent / Policy Engine 保持标准无关，Core 不 import ACS（§二）。

### 2. 映射语义（关键决策记录）

- **allow** → allow；**deny** → deny（保留 reasoning/ruleId）；**deny+safeAlternative** → **modify**（Modification Proposal，只提议不执行，§十二）；**ask** → ask（§十三）；**defer** 仅协议支持（§十四）。
- **intent 只作 contextual evidence**：放入 `context.metadata.intent`，绝不直接决定 allow（§七）。
- **raw_command 触发 classifyShellCommand 细化**：`shell.execute` + `git reset --hard` → git.git_reset → RG-GIT-001 deny；只读命令（`isReadOnlyCommand`）→ filesystem.read（Profile B 放行，与 vendor adapter 同模式）。
- **非法输入 fail-closed**：deny + `extensions.riskguard.degraded=true`，无 stack trace（§十八）。
- **reasoning 四要素**：rule ID + risk category + operation + reason（§十五）。
- 未知 capability / credentials.write / mcp.invoke 近似映射明确标注 `exact:false`（保守方向）。

### 3. Compatibility Schema v2（§二十~§三十六）

- `compatibility.json` → `schemaVersion "2.0"`；每 Agent 增加 surfaces / enforcementDetail / sandbox / policy(policyScope) / bypass / hookFailureSemantics / conditionalAvailability / securityBoundaries(L0–L5) / capabilities / componentInventory(AGBoM 预留)。
- **v1→v2 loader 迁移**（§四十一）：`parseCompatibility()` 兼容 1.0/2.0；v2 未声明字段默认 unknown，不伪造 false（§二十三）。
- Windsurf 记录 `conditionalAvailability: hook @ Restricted Mode disabled`（§三十一）。
- 全部 agent 记录 hookFailureSemantics（§三十二）；grok 诚实 fail-open。
- `docs/generated/agent-security-matrix.md` 自动生成（§二十四），CI `--check` 防漂移。
